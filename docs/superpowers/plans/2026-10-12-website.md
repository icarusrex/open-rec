# OpenREC Website Implementation Plan

> **For agentic workers:** Execute with superpowers:executing-plans in this chat. Steps use checkbox syntax for tracking.

**Goal:** Publish a sourced, useful Portugal-first energy-community resource hub.
**Architecture:** Generate six static HTML pages using Node and shared JSON. Enhance directories and a checklist in browser JavaScript. Deploy dist to Cloudflare Pages.
**Tech Stack:** Node 22+, native ES modules, HTML, CSS, SVG, node:test, Cloudflare Pages.
**Spec:** docs/superpowers/specs/2026-10-12-website-design.md

## Global Constraints
- Source in website/; target openrec.viableplanet.eu on the user's Cloudflare account.
- No production dependencies, personal-data forms, analytics, or third-party runtime scripts.
- Charcoal #111411, cream #F5F1E8, amber #EDBC54, teal #86BBAA, muted #B6B9AE.
- All source dates unknown unless disclosed; dates checked 2026-10-12.
- Clearly distinguish ACC, CER, CCE, reported community activity, and prototype/roadmap capabilities.
- No em dash in authored content.

## Review Focus
- Accented and mixed-case searches must find Portuguese records.
- Combined filters and reset must preserve accurate counts and empty states.
- Corrupted or unavailable browser storage must not break checklist use.
- Unknown dates and legal status must not appear as fabricated current facts.
- Small screens, keyboard users, and no-JavaScript visitors must retain navigation and core content.
